# Нейро-Нечеткая Система Реконструкции Нейтронных Спектров (XAI 2.0)

Проект для восстановления спектров нейтронов по показаниям детектора (сферы Боннера) с использованием адаптивной нейро-нечеткой системы (ANFIS) и объяснимого искусственного интеллекта (SHAP).

## 🚀 Ключевые особенности (XAI 2.0)

*   **Высокая точность:** R² > 0.84 на реальных экспериментальных данных.
*   **Интерпретируемость:** Использование SHAP (Shapley Additive exPlanations) не только для анализа, но и **для обучения** (регуляризация модели).
*   **Гибридная архитектура (Hybrid Integrated):**
    1.  **Глобальный поиск:** PSO (Particle Swarm Optimization) находит оптимальную структуру правил в невыпуклом ландшафте.
    2.  **Интеграция смысла:** Градиентный спуск (Adam) внедряет SHAP-ограничения (разреженность, стабильность), используя "мягкий старт" (Warmup) и дифференциальные скорости обучения.

## 📂 Структура проекта

*   `src/` - Исходный код моделей и утилит.
    *   `models/` - Реализация ANFIS, SHAP тренеров.
*   `configs/` - Конфигурационные файлы YAML.
*   `results/` - Результаты обучения (модели, графики, логи).
*   `train.py` - Основной скрипт обучения.

## 🏁 Как запустить (Релизная версия)

Мы объединили все наработки в один универсальный конфигурационный файл. Для воспроизведения лучших результатов (`hybrid_v12`):

```bash
source ~/venv/bin/activate
python3 train.py --config configs/config_integrated_shap.yaml --tag official_release
```

*Этот конфиг настроен на гибридный режим: сначала PSO (150 эпох) для точности, затем SHAP (300 эпох) для объяснимости.*

## 📊 Результаты

### Лучшая модель (`hybrid_v12_final`)
Финальная модель показала следующие результаты на тестовой выборке (100% реальные данные):

*   **MSE:** **0.0106** (Минимальная ошибка)
*   **Качество объяснений:** Модель использует минимально необходимый набор детекторов (Sparsity) и устойчива к шуму (Stability).

| Метод | R² | Описание |
| :--- | :--- | :--- |
| **Vanilla ANFIS** | **0.90** | Максимальная точность (эталон), но "черный ящик". |
