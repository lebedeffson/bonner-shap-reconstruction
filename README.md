## 📖 Описание

Система восстанавливает энергетические спектры нейтронов из показаний детекторов Боннера (10 детекторов Q1-Q10) в 60 энергетических бинов в диапазоне от **10⁻³ до 10⁸ эВ**. 

Модель использует **двухэтапное обучение**:
1. **Базовая ANFIS модель** с оптимизацией PSO (Particle Swarm Optimization)
2. **SHAP-регуляризация** для улучшения интерпретируемости и точности

### Научная основа

Проект основан на работе К.А. Чижова и др. (Системный анализ в науке и образовании, 2025) и использует:
- ANFIS (Adaptive Neuro-Fuzzy Inference System) для нечеткого логического вывода
- SHAP (SHapley Additive exPlanations) для регуляризации и интерпретации
- Нормализацию на сумму сигналов (SUM) для стабильности обучения

## ✨ Основные возможности

- **Мультирегрессия** на 60 энергетических бинов одновременно
- **Нормализация на SUM** - входы и выходы нормализуются по сумме сигналов детекторов
- **Двухэтапное обучение**: Vanilla ANFIS (PSO) → SHAP-регуляризация

### Модули исходного кода

#### `src/models/anfis_manager.py`

**Класс `ANFISManager`**

Менеджер для создания, обучения и оценки ANFIS моделей.

**Основные методы:**
- `create_model()` - создание ANFIS модели с заданными параметрами

- `_calculate_metrics()` - вычисление метрик (MSE, RMSE, MAE, R²)
- `_extract_feature_importance()` - извлечение важности признаков
- `_log_and_clean_state()` - очистка NaN/Inf из параметров модели
- `_sanitize_predictions()` - очистка предсказаний от некорректных значений

**Особенности:**
- Автоматическая обработка NaN/Inf в коэффициентах
- Умная замена NaN медианой вместо нуля

- Вычисление метрик по энергетическим диапазонам

#### `src/models/shap_trainer.py`

**Класс `ShapAwareANFISTrainer`**

Тренер для SHAP-регуляризованного обучения ANFIS модели.

**Основные методы:**
- `fit()` - обучение модели с SHAP-регуляризацией
- `predict()` - получение предсказаний
- `get_global_shap_importance()` - вычисление глобальной важности признаков
- `_calculate_shap_approximation()` - приближенное вычисление SHAP значений

**Особенности:**
- Градиентный клиппинг для стабильности
- Штраф за отрицательные предсказания
- Проверка градиентов на NaN/Inf

## ⚙️ Конфигурация

Все параметры обучения настраиваются в `configs/config.yaml`:

### Секция `dataset`

```yaml
dataset:
  train_data: normalized_linear_data_with_q_500K.csv  # Путь к обучающим данным
  validation_data: normalized_data_with_q_375.csv      # Путь к валидационным данным
  normalize_sum: true                                   # Нормализация на SUM
  mix_with_real: true                                   # Смешивание с реальными данными
  mix_ratio: 0.01                                       # Доля реальных данных (1%)
  test_size: 0.25                                       # Доля тестовой выборки
  random_state: 42                                      # Seed для воспроизводимости
```

### Секция `model`

```yaml
model:
  num_rules: 10                    # Количество нечетких правил
  mf_class: Gaussian               # Функция принадлежности (Gaussian, GBell, Triangular)
  vanishing_strategy: blend        # Стратегия устранения затухания
  optim: OriginalPSO               # Оптимизатор (OriginalPSO, PSO, GA)
  reg_lambda: 0.2                  # Коэффициент L2-регуляризации
  seed: 42                         # Seed для воспроизводимости
  n_workers: 4                     # Количество потоков для параллельных вычислений
  optim_params:
    epoch: 25                       # Количество эпох PSO
    pop_size: 40                    # Размер популяции PSO
    verbose: false                  # Вывод информации о процессе
```

### Секция `shap_reg`

```yaml
shap_reg:
  enabled: true                    # Включить SHAP-регуляризацию
  gamma: 0.5                        # Коэффициент SHAP-регуляризации
  epochs: 35                        # Количество эпох SHAP обучения
  batch_size: 32                    # Размер батча
  lr: 0.002                         # Скорость обучения
  grad_clip: 1.0                    # Максимальная норма градиентов
  negative_penalty: 0.1             # Штраф за отрицательные предсказания
```

### Секция `output`

```yaml
output:
  results_dir: results              # Директория для результатов
  save_model: true                  # Сохранять модель
  save_predictions: true             # Сохранять предсказания
  save_plots: true                  # Генерировать графики
  save_samples: true                 # Сохранять выборку спектров
  sample_size: 5                     # Размер выборки для сохранения
```

## 🔬 Технические детали

### Архитектура ANFIS

ANFIS (Adaptive Neuro-Fuzzy Inference System) - гибридная нейро-нечеткая система:

1. **Слой фаззификации**: Преобразует входные значения в степени принадлежности
2. **Слой правил**: Применяет нечеткие правила (AND операции)
3. **Слой нормализации**: Нормализует веса правил
4. **Слой дефаззификации**: Линейные комбинации для каждого правила
5. **Выходной слой**: Суммирование взвешенных выходов правил

**Параметры модели:**
- Количество правил: определяет сложность модели
- Функции принадлежности: форма нечетких множеств
- Коэффициенты правил: линейные параметры выходного слоя

### Оптимизация PSO

Particle Swarm Optimization (PSO) используется для обучения параметров ANFIS:

- **Популяция**: набор частиц (кандидатных решений)
- **Позиция частицы**: вектор параметров модели
- **Скорость**: направление и скорость изменения позиции
- **Глобальный лучший**: лучшее решение во всей популяции
- **Локальный лучший**: лучшее решение для конкретной частицы

**Параметры PSO:**
- `epoch`: количество итераций
- `pop_size`: размер популяции
- `c1`, `c2`: коэффициенты ускорения
- `w`: коэффициент инерции

### SHAP-регуляризация

SHAP (SHapley Additive exPlanations) регуляризация улучшает интерпретируемость:

1. **Вычисление SHAP значений**: важность каждого признака для предсказания
2. **Регуляризация**: штраф за неравномерное распределение важности
3. **Целевой профиль**: равномерное распределение важности признаков
4. **Градиентное обучение**: дообучение модели с учетом SHAP потерь

**Преимущества:**
- Улучшенная интерпретируемость модели
- Более равномерное использование признаков
- Потенциальное улучшение обобщающей способности

### Обработка данных

**Нормализация на SUM:**
- Все входные сигналы делятся на SUM = Σ(Qi)
- Все выходные спектры делятся на тот же SUM
- Обеспечивает масштабную инвариантность
- Улучшает стабильность обучения

**Денормализация:**
- Предсказания умножаются на SUM для получения физических значений
- Автоматически выполняется при сохранении результатов

### Обработка ошибок

**NaN/Inf обработка:**
- Проверка входных данных перед обучением
- Очистка параметров модели после обучения
- Умная замена NaN медианой вместо нуля
- Проверка предсказаний на валидность

**Градиентный клиппинг:**
- Ограничение нормы градиентов для предотвращения взрывающихся градиентов
- Настраивается через `shap_reg.grad_clip`

**Штраф за отрицательные предсказания:**
- Физически спектры не могут быть отрицательными
- Добавление штрафа в функцию потерь
- Обрезка отрицательных значений после предсказания
