# Нейро-Нечеткая Система Реконструкции Нейтронных Спектров (XAI 2.0)

Проект для восстановления спектров нейтронов по показаниям детектора (сферы Боннера) с использованием адаптивной нейро-нечеткой системы (ANFIS) и объяснимого искусственного интеллекта (SHAP).

## 🚀 Ключевые особенности

*   **Высокая точность:** R² > 0.84 на реальных экспериментальных данных.
*   **Интерпретируемость (XAI 2.0):** Использование SHAP (Shapley Additive exPlanations) для объяснения решений модели.
*   **Гибридное обучение:** Комбинация PSO (Particle Swarm Optimization) для грубой настройки и градиентного спуска с SHAP-регуляризацией для тонкой настройки.
*   **Физическая корректность:** Штрафы за отрицательные значения спектра и сглаживание.

## 📂 Структура проекта

*   `src/` - Исходный код моделей и утилит.
    *   `models/` - Реализация ANFIS, SHAP тренеров.
*   `configs/` - Конфигурационные файлы YAML.
*   `results/` - Результаты обучения (модели, графики, логи).
*   `train.py` - Основной скрипт обучения.
*   `plot_results.py` - Скрипт визуализации.

## 🏁 Быстрый старт

Для запуска обучения с лучшей конфигурацией:

```bash
source ~/venv/bin/activate
python3 train.py --config configs/config_hybrid_shap.yaml --tag final_run
```

## 📊 Результаты (v12 Hybrid SHAP)

Финальная модель (`hybrid_v12_final`) показала следующие результаты на тестовой выборке (реальные данные):

*   **MSE:** 0.0106
*   **R² (взвешенный):** 0.837
*   **R² (средний по бинам):** 0.556

### Используемые методы
1.  **Инициализация:** PSO (150 эпох) для нахождения глобального оптимума.
2.  **Fine-tuning:** 300 эпох градиентного спуска с добавлением SHAP-регуляризации (Consistency, Sparsity).
3.  **Данные:** Обучение и тестирование проводилось исключительно на реальных экспериментальных данных (без смешивания с синтетикой).

## 🔧 Конфигурации

В проекте оставлены 3 ключевые конфигурации:
1.  `config_vanilla_r2_09.yaml` - Базовая ANFIS (без SHAP), высокая точность (R² ~0.9).
2.  `config_vanilla_shap_real.yaml` - Двухэтапное обучение с фиксированной Gamma.
3.  `config_hybrid_shap.yaml` - **Рекомендуемая.** Гибридный подход (PSO + SHAP Fine-tuning).
