## 📖 Описание

Система восстанавливает энергетические спектры нейтронов из показаний детекторов Боннера (10 детекторов Q1-Q10) в 60 энергетических бинов в диапазоне от **10⁻³ до 10⁸ эВ**.

### Архитектура обучения

**Текущий подход:** Сначала добиваемся максимальной точности на чистой ANFIS модели, затем добавим интерпретируемость через SHAP-регуляризацию.

**Этап 1: Vanilla ANFIS (текущий фокус)**
1. **PSO инициализация** - начальная оптимизация параметров модели
2. **Чистое обучение ANFIS** - без дополнительной регуляризации
3. **Оптимизация параметров** - подбор количества правил, регуляризации, функций принадлежности
4. **Цель:** Достичь максимального R² на реальных данных

**Этап 2: SHAP-регуляризация (после достижения лучшего результата)**
1. **Интегрированная SHAP-регуляризация** - встроена в loss функцию
2. **Адаптивные механизмы** - автоматическая адаптация к точности модели
3. **Интерпретируемость** - объяснимость предсказаний через SHAP значения
4. **GPU ускорение** - автоматическое использование CUDA при наличии

**⚠️ Важное наблюдение:** SHAP-регуляризация показала нестабильность при обучении с нуля на малом датасете (300 реальных образцов):
- Появление NaN значений в loss после ~20-60 эпох
- Нестабильность градиентов из-за вычисления SHAP для всех подмножеств признаков (2^10 = 1024)
- Низкая точность (R² < 0.1) по сравнению с vanilla моделью (R² = 0.86)

**Варианты решения:**
1. **Использовать предобученную vanilla модель** - загрузить лучшую vanilla модель (R²=0.8638) и дообучить её с SHAP регуляризацией
2. **Добавить синтетические данные** - использовать режим `full_fast` с большим количеством синтетических данных для стабильности обучения
3. **Упростить SHAP вычисления** - использовать только gradient-based importance без точных Shapley values для уменьшения вычислительной сложности

### Научная основа

Проект основан на работе К.А. Чижова и др. (Системный анализ в науке и образовании, 2025) и использует:
- **ANFIS** (Adaptive Neuro-Fuzzy Inference System) для нечеткого логического вывода
- **SHAP** (SHapley Additive exPlanations) для регуляризации и интерпретации
- **Нормализацию на SUM** для стабильности обучения

## ✨ Основные возможности

### 🎯 Модель и обучение

- **Мультирегрессия** на 60 энергетических бинов одновременно
- **Нормализация на SUM** - входы и выходы нормализуются по сумме сигналов детекторов
- **Интегрированное обучение** - SHAP регуляризация встроена в loss функцию с начала обучения
- **Улучшенная SHAP регуляризация** с 4 компонентами:
  - **Consistency** - согласованность с настоящими Shapley values
  - **Sparsity** - разреженность важности признаков (Gini coefficient)
  - **Faithfulness** - верность объяснений
  - **Stability** - стабильность объяснений
- **Адаптивные веса компонентов** - автоматическая адаптация к точности модели
- **GPU ускорение** - автоматическое использование CUDA
- **Автоматическая обработка NaN/Inf** - стабильное обучение без численных ошибок
- **Градиентный клиппинг** - предотвращение взрывающихся градиентов

## ⚙️ Конфигурация

### Vanilla ANFIS конфигурация (`configs/config_vanilla_r2_09.yaml`)

**Текущий лучший результат:** R² = 0.8638

Оптимизирована для максимальной точности на реальных данных:

```yaml
dataset:
  train_data: normalized_data_with_q_375.csv  # Только реальные данные
  normalize_sum: true
  test_size: 0.25  # 75% train, 25% test

model:
  num_rules: 50                    # Большая емкость модели
  mf_class: GBell                  # GBell лучше для пиков спектра
  reg_lambda: 0.001                # Минимальная регуляризация
  optim_params:
    epoch: 150                     # Много PSO эпох для лучшей инициализации
    pop_size: 200                  # Большая популяция

shap_reg:
  enabled: false                   # SHAP отключен - чистая ANFIS
```

### SHAP конфигурация (`configs/config_improved.yaml`)

Для добавления интерпретируемости после достижения лучшего результата:

```yaml
model:
  num_rules: 20
  reg_lambda: 0.1

shap_reg:
  enabled: true                    # SHAP включен
  integrated_training: true         # Интегрированное обучение
  use_gpu: true                    # Автоматическое использование GPU
  gamma: 0.3                       # Коэффициент SHAP регуляризации
  epochs: 200
  batch_size: 64
  use_improved_shap: true          # Улучшенная SHAP регуляризация
  use_adaptive_weights: true       # Адаптивные веса компонентов
  use_gini_sparsity: true          # Gini coefficient для sparsity
```

## 🔬 Технические детали

### Архитектура ANFIS

ANFIS (Adaptive Neuro-Fuzzy Inference System) - гибридная нейро-нечеткая система:

1. **Слой фаззификации**: Преобразует входные значения в степени принадлежности
2. **Слой правил**: Применяет нечеткие правила (AND операции)
3. **Слой нормализации**: Нормализует веса правил
4. **Слой дефаззификации**: Линейные комбинации для каждого правила
5. **Выходной слой**: Суммирование взвешенных выходов правил

**Параметры модели:**
- `num_rules`: количество нечетких правил (емкость модели)
- `mf_class`: функция принадлежности (Gaussian, GBell, Triangular)
- `reg_lambda`: коэффициент L2-регуляризации

### SHAP-регуляризация (отложено)

**⚠️ Статус:** SHAP регуляризация отложена из-за нестабильности на малом датасете.

**Проблема:** При обучении с нуля на малом датасете (300 реальных образцов) наблюдалась:
- Появление NaN значений в loss после ~20-60 эпох
- Нестабильность градиентов из-за вычисления SHAP для всех подмножеств признаков (2^10 = 1024)
- Низкая точность (R² < 0.1) по сравнению с vanilla моделью (R² = 0.86)

**Варианты решения:**
1. Использовать предобученную vanilla модель и дообучить её с SHAP
2. Добавить синтетические данные (режим `full_fast`) для стабильности
3. Упростить SHAP вычисления (только gradient-based importance)

**Теоретическая основа:** SHAP регуляризация встроена в loss функцию с начала обучения:

```
L_total = L_main + γ * L_SHAP
```

Где:
- `L_main` - основная функция потерь (MSE)
- `L_SHAP` - улучшенная SHAP регуляризация с 4 компонентами
- `γ` - адаптивный коэффициент регуляризации

**Компоненты SHAP регуляризации:**

1. **Consistency** - согласованность с настоящими Shapley values
   - Комбинация MSE и JS Divergence
   - Адаптивный вес между компонентами
   - Обеспечивает правильность объяснений

2. **Sparsity** - разреженность важности признаков
   - Комбинация Shannon Entropy и Gini coefficient
   - Адаптация к точности модели
   - Выделяет наиболее важные признаки

3. **Faithfulness** - верность объяснений
   - Проверка локальной линейности
   - Адаптивный вес (уменьшается для неточных моделей)
   - Гарантирует, что объяснения соответствуют поведению модели

4. **Stability** - стабильность объяснений
   - Минимизация дисперсии важности
   - Адаптивный вес
   - Обеспечивает стабильность объяснений на похожих данных

**Адаптивные веса компонентов:**
- Если модель неточная → больше веса на Consistency (помогает точности)
- Если модель точная → больше веса на Sparsity (улучшает интерпретируемость)

**Когда использовать SHAP:**
- После достижения максимальной точности на vanilla модели
- Когда требуется объяснимость предсказаний
- Для военных применений, где важна интерпретируемость

### GPU ускорение

Система автоматически определяет и использует GPU:

- Проверка доступности CUDA
- Автоматическое перемещение модели на GPU
- Использование GPU для вычисления SHAP значений
- Fallback на CPU если GPU недоступен

### Обработка данных

**Нормализация на SUM:**
- Все входные сигналы делятся на SUM = Σ(Qi)
- Все выходные спектры делятся на тот же SUM
- Обеспечивает масштабную инвариантность

**Денормализация:**
- Предсказания умножаются на SUM для получения физических значений
