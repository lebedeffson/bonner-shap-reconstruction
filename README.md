# ANFIS Bonner Spectra Reconstruction

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-Scientific%20Use-green.svg)](LICENSE)

Проект по восстановлению энергетических спектров нейтронов по показаниям многошарового спектрометра Боннера с использованием **XAI 2.0: Обучение с объяснениями** (Integrated SHAP Regularization).

## 🌟 Ключевой результат (XAI 2.0)

Мы успешно реализовали **двухэтапное обучение**, объединяющее высокую точность классической ANFIS модели с интерпретируемостью SHAP-регуляризации.

| Модель | R² (Точность) | MSE | Интерпретируемость | Описание |
|--------|--------------|-----|-------------------|----------|
| **XAI 2.0 (Two-Stage)** | **0.8485** | **0.0099** | ✅ **Высокая** | **Рекомендуемая.** Сохраняет точность, добавляет объяснимость (Sparsity, Consistency). |
| Vanilla ANFIS | 0.8763 | 0.0079 | ❌ Низкая | Базовая модель без регуляризации. Чуть точнее, но "черный ящик". |
| Integrated SHAP (v1) | < 0.0 | > 0.1 | ✅ Высокая | Неудачная попытка обучения с нуля (слишком агрессивная регуляризация). |

## 🚀 Что такое XAI 2.0?

Вместо того чтобы объяснять модель *после* обучения (Post-hoc XAI), мы внедряем требования к объяснимости **прямо в процесс обучения** (In-process XAI).

**Алгоритм Two-Stage Training:**
1.  **Этап 1 (Anchor):** Обучение "ванильной" ANFIS модели с помощью PSO (Particle Swarm Optimization). Цель: найти глобальный минимум ошибки (MSE).
2.  **Этап 2 (Fine-tuning):** Дообучение модели градиентным спуском с добавлением **SHAP-регуляризации**.
    *   `Loss = MSE + γ * (Sparsity + Consistency + Faithfulness)`
    *   Модель учится сохранять точность, но "очищает" свои веса, чтобы быть более разреженной и понятной.

## 📊 Основные возможности

### 🎯 Модель
*   **Мультирегрессия**: Восстановление 60 энергетических бинов одновременно.
*   **Нормализация**: Полная инвариантность к интенсивности источника (нормализация на SUM).
*   **XAI-ядро**: Интегрированная SHAP-регуляризация с 4 компонентами:
    *   **Consistency**: Согласованность с теорией игр (Shapley Values).
    *   **Sparsity**: Выделение ключевых детекторов (Gini index).
    *   **Faithfulness**: Честность объяснений (локальная точность).
    *   **Stability**: Устойчивость к шуму.

### 📈 Результаты
*   R² > 0.84 на реальных экспериментальных данных.
*   Автоматическая генерация отчетов:
    *   Сравнение спектров (True vs Predicted).
    *   Анализ важности признаков (Feature Importance).
    *   Гистограммы ошибок.

## 🛠 Быстрый старт

### 1. Установка
```bash
git clone <repo-url>
cd ОИЯИ-ШАБД
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск обучения (XAI 2.0)
Запустите полный цикл обучения (Vanilla -> SHAP Fine-tuning):

```bash
python3 train.py --config configs/config_vanilla_shap_real.yaml --tag xai_final
```

### 3. Результаты
Все результаты сохраняются в папку `results/`:
*   `*.pt` - файлы модели.
*   `*.json` - метрики и история обучения.
*   `*.png` - графики.

## ⚙️ Конфигурация (`configs/config_vanilla_shap_real.yaml`)

Оптимальные параметры, найденные в ходе экспериментов:

```yaml
shap_reg:
  enabled: true
  integrated_training: false   # Двухэтапное обучение (важно!)
  gamma: 0.1                   # Мягкая сила регуляризации
  epochs: 25                   # Короткий этап дообучения
  use_adaptive_gamma: false    # Фиксированная гамма для стабильности
```

## 📁 Структура проекта

*   `src/models/` - Ядро ANFIS и SHAP тренеры.
*   `configs/` - Конфигурационные файлы YAML.
*   `train.py` - Единая точка входа для обучения.
*   `results/` - Артефакты обучения (не игнорируются git).
